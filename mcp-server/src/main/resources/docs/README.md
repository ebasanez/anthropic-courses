# mcp-server documents

Everything in this folder — `mcp-server/src/main/resources/docs` — is published over
MCP by `DocsResources`, subfolders included. Nothing outside it is.

Read `docs://mcp-server` for the list of URIs. This file is
`docs://mcp-server/README.md`; paths are relative to this folder, so the `docs/`
prefix is not part of them.
